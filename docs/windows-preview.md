# Toccata Windows Preview

更新日期：2026-11-02。Windows 预览版 `0.1.3-win.2` 在上游 v0.1.3 / build 21 迁移基础上补齐任务排序、手动保存、返回父任务和音效/拖拽交互，详见 [任务交互更新](windows-task-updates.md) 与 [上游迁移说明](windows-upstream-v013.md)。[此版本发布入口](https://github.com/WenNinghan/Toccata-Windows/releases/tag/v0.1.3-win.2)。初始非官方 Windows 移植基于 [KMnO4-zx/Toccata](https://github.com/KMnO4-zx/Toccata) 0.1.0，基线提交 `4e3f89e4ceee03033e49722d162158f51bbea743`。Preview 是本移植的交付状态，不是已完成全部验收的正式版。

## 能做什么

- 任务与收集箱、子任务、Markdown 详情、计划日期、任务日历、回顾与复制。优先级采用灰色无优先级、蓝色低、橙色中、红色高，列表与详情保留文字标签。
- Windows 原生窗口与系统托盘，关闭窗口收起到托盘，任务自动保存；主详情和浮窗支持保存按钮与 Ctrl+S、返回父任务。
- 普通列表和日历的已完成任务按完成时间倒序；子任务在各处采用统一顺序，支持带插入位置提示的拖拽。托盘任务页保留用户选择的排序。
- 普通按键、修饰键、导航区与小键盘采集、长按重复过滤、活跃时间线、热图、应用排行和图片分享。
- 68/84/87/104 键代表性布局及位置、尺寸、标签自定义；深浅主题和中英文界面。
- 通用配置、可选喝水提醒、托盘活动速览、使用占比和主题化筛选（`0.1.3-win.1` 新增）。
- Windows 第三指标为平均击键频率，按有效按键次数除以活跃分钟计算；替代上游 Fn 语音时长估算。

## 首次使用

1. 已验证环境为 **Windows 11 x64**。其他 Windows 版本、ARM64、多显示器动态缩放尚未完整验收。
2. 在发布页的 Assets 下载 **`Toccata-Windows-v0.1.3-win.2-x64.zip`**。`Toccata-Windows-source-v0.1.3-win.2.zip` 是源码；GitHub 自动生成的 Source code 也不是可运行程序。将整个程序 ZIP 解压到可写文件夹，例如非系统盘，不要在压缩包里直接运行，也不要只复制一个 EXE。
3. 运行程序子目录里的 `Toccata.exe`。无需另装 Node.js 或 GCC；这些只用于源码开发。本预览未签名，Windows 可能提示来源未知。
4. **正常启动即开始记录键盘活动**。点击窗口关闭按钮只是收起到托盘，仍继续记录；要停止记录，请在系统托盘右键 Toccata，选择“退出 Toccata”。当前没有界面内的暂停开关。
5. 添加任务：输入名称后点击加号、提交箭头或按 Enter。任务详情使用自动保存，也可点击保存按钮或按 Ctrl+S，留意“已保存”状态。输入法组词尚未确认时会等待组词结束再保存；保存失败时保留草稿，并停止返回父任务操作。

## 数据、备份与升级

程序会记录物理按键代码、时间、按住时长和前台应用归属，保存在本地。它不直接保存输入的文字，也不截图或录音，但**按键序列仍可能透露输入内容**。不要把自己的运行数据作为演示数据上传或分享；输入不希望被记录的内容之前可先退出程序。

数据文件夹位于程序文件夹的上一级，名称为 `Toccata-data`。例如 `Toccata-Windows-preview/Toccata/Toccata.exe` 使用 `Toccata-Windows-preview/Toccata-data`。它包含任务、按键记录、自定义布局、设置、应用身份及密钥，应作为一个整体备份。

- **备份**：从托盘退出后，完整复制 `Toccata-data` 到自己的备份位置。
- **升级**：从托盘退出后，只替换 `Toccata` 程序子目录，保留同级 `Toccata-data`。如果换了整个解压目录，请在首次启动前把旧数据文件夹完整复制到新位置。
- **移除程序**：退出后可删除程序目录；数据单独保留。确认不再需要记录时，再自行处理数据文件夹。

从 `0.1.3-win.1` 起，“关于 → 检查 Windows 更新”使用 Windows Fork 渠道，支持 ZIP 下载、SHA256 校验及手动触发安装；首次从 2026-10-29 旧公开体验包升级仍需手动替换。发布页附带 `SHA256SUMS.txt` 供手动校验。采集过程不上传记录；用户手动点击“检查更新”时会向 GitHub 请求发布元数据。

## 已知问题和差异

此前审计中的任务差距 T2–T7 已在 `0.1.3-win.2` 补齐：任务与子任务排序、保存按钮/Ctrl+S、返回父任务、不叠加的完成音效、拖拽把手及插入/落位反馈。以下限制继续保留。

| 项目 | 当前状态或临时操作 |
|---|---|
| 应用图标 | 优先读取程序或 Windows 安装包的高清资源；旧缓存会在再次使用对应应用时更新。历史应用若已卸载或不再运行，无法仅凭匿名身份恢复图标；源程序素材分辨率也会限制清晰度。 |
| 特殊键 | 不虚构 Fn 事件；Pause 未映射，部分 Print Screen/媒体键待实机验证。预设不代表自动识别全部键盘硬件。 |
| 应用排行 | 页面会加入未松开的实时长按，分享使用已提交快照；与原版应用排行口径有差异。 |
| 大量历史记录 | 尚无原版的按天统计缓存，长期数据量下的时延与内存需要规模验证。 |
| 系统行为 | 锁屏、会话切换、UAC、多设备复杂组合、长时间运行及多屏动态 DPI 尚未完整验收。 |
| 其他 | Mac 历史库没有自动导入；部分英文界面仍保留中文预设名称。 |

本预览不标注“100% 功能对齐”或“完整稳定”。反馈问题时请提供操作步骤、系统版本、主题/缩放和截图；分享截图或日志前自行检查私人内容，**不要直接提交日常数据库或 `app-identity.key`**。

## 验证与开发

验证覆盖隔离任务持久化、合成事件贯通、分享计算、实时更新、设置、喝水提醒、托盘活动、按键占比、Windows 更新和失败回滚。任务输入与计划日期专项覆盖持续输入、中文合成及跨窗口编辑；优先级颜色覆盖主窗口、日历、子任务、托盘、浮窗、深浅主题和保存失败回退。打包程序单独检查启动、写入、退出、重启持久化。这些结果不能替代全部实体硬件和长期运行验收；本次运行结果以发布说明为准。

`0.1.3-win.2` 于 2026-11-02 完整串行回归 174 项，173 passed、0 failed、1 skipped，耗时 166.10 秒；跳过项为真实采集 helper 的 ready/quit 握手。原生程序 self-test、全新依赖安装和构建均通过；打包 EXE 的启动、写入、退出、重启持久化检查为 1 passed。包内运行文件与对应源码字节一致，未包含运行数据或私人文件。任务交互及合成数据界面见 [更新说明](windows-task-updates.md)。

历史记录：`0.1.3-win.1` 的完整串行回归为 146 项、145 passed、0 failed、1 skipped，属于上一版结果。输入法测试使用合成组合事件，通知与登录项使用模拟服务；全部实体输入法、系统通知、特殊硬件和长期系统行为仍需实机验证。

源码及已验证工具链见 [Windows 开发说明](../apps/toccata-windows/README.md)。部分测试仍使用本机 G 盘目录，公开源码的测试可移植性待补；完整并行测试有过退出等待超时，原因尚未确定。
